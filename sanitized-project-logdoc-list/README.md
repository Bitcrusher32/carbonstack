# Project Sanitized LogDoc List

Attached in this directory are "LogDoc" markdown files, with potentially identifiable information sanitized.
Logdoc is a human-in-loop engineering system which uses tightly scoped goals and project context preservation.
The system facilitates bounded LLM + human loop-style iteration, acting as a time-force multiplier and project management tool.

**LogDoc files are included for developer context, preserving failure modes encountered, why certain decisions were made, and the carbonstack development process**

_For more information on LogDoc, see the repository: [logdoc-loop-system](https://git.bitcrusher32.win/bitcrusher32/logdoc-loop-system)_
