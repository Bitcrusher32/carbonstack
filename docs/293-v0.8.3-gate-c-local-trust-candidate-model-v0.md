## Adversarial seed cases

The Gate B seed is carried forward and Gate C adds a small seed pack:

```text
ADV-TRUST-RELAY-MEMBERSHIP-NOT-TRUST-001
ADV-TRUST-LABEL-SPOOF-NOT-IDENTITY-001
ADV-TRUST-MLS-JOIN-NOT-TRUST-001
ADV-TRUST-PROVIDER-OBSERVATION-NOT-TRUST-001
ADV-TRUST-CHANGED-SIGNER-LOUD-WARNING-001
ADV-TRUST-CHANGED-DEVICE-LOUD-WARNING-001
ADV-TRUST-AUTOPROMOTION-REFUSED-001
```

## Meaning

Relay membership is not trust. MLS join is not trust. Provider observation is not trust.

The operator can correlate human label, Cypher account/device, Relay Space context, OpenMLS signer/credential fingerprint, KeyPackage lineage, and verification method into a local candidate. Correlation is not cryptographic unification and not real-world identity proof.

Promotion to `promoted_local_trust` requires an explicit operator promotion event and verification method. Changed signer/device/key lineage becomes a loud warning state and blocks promotion until handled.
