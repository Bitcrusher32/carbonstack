# v0.8.8 Gate G Operator Lifecycle Report Model v0

## Status

Gate G3 report model.

Schema marker: `carbonstack-gate-g-operator-lifecycle-report/v0`

## Required report fields

- `schema_version`
- `profile`
- `status`
- `safe_summary_stdout`
- `detailed_evidence_root_policy`
- `preferred_aggregate`
- `full_runtime_dev`
- `containers`
- `public_ingress_default`
- `subgates`
- `exit_policy`
- `carried_findings`
- `nonclaims`

## Required values

```text
schema_version=carbonstack-gate-g-operator-lifecycle-report/v0
profile=operator-lifecycle-dev
preferred_aggregate=operator-lifecycle-dev
full_runtime_dev=reserved_not_promoted
containers=deferred_late_v0.9.x_or_v0.10.0
public_ingress_default=disabled
service_systemd_helper_status=conditional_g4_local_private_substrate
public_ingress_status=conditional_g5_threat_model_prototype_substrate
```

## Safe summary stdout

The operator-facing default output must summarize:

- current lifecycle stage;
- next allowed subgate;
- public-ingress default state;
- service/systemd/helper state;
- container deferment;
- `full-runtime-dev` reservation;
- high carried findings;
- nonclaims.

The output must avoid printing account identifiers, device identifiers, Relay Space identifiers, invite codes, KeyPackage details, local DB paths, state roots, runtime roots, secrets, private keys, passwords, and detailed local process state.

## Detailed evidence

Detailed evidence belongs in evidence-root logs or reports written by outer scripts. The profile may expose machine-readable model details through tests and report builders, but stdout remains safe-summary only.

## Carried findings

- `ADV-NATIVE-LOG-LEAKAGE-001`: high, carried from Gate F F3/F4.
- `ADV-NATIVE-GENERATED-ARTIFACTS-001`: medium, carried WSL artifact-hygiene debt.

## Nonclaims

The report is not public UX stability, production readiness, public deployment readiness, public-ingress safety, service readiness, systemd readiness, helper install readiness, container readiness, release/package mutation, verified identity, malicious-relay safety, metadata privacy, PQ/hybrid support, external audit, or external pen-test completion.
