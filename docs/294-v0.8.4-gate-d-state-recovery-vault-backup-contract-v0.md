# Gate D v0.8.x State / Recovery / Vault-Backup Contract

Status: dev/pre-alpha Gate D contract artifact
Checkpoint: v0.8.4 Gate D state/recovery/migration/vault-backup model refresh
Scope: state inventory, recovery classification, migration compatibility classification, backup manifest model, rollback metadata inspection, non-secret dry-run classification, and no-silent nonclaims

## Purpose

Gate D reconciles current code with the older state, vault, security, and no-silent model lineage without overclaiming a secure vault.

Gate D is not a production vault. Gate D is not encryption-at-rest. Gate D is not secure key storage. Gate D is not production backup/restore. Gate D is not migration safety.

This rung creates a bridge toward the full backup/restore/vault pipeline that is practically needed before v0.9.x external adversarial method and red-team analysis, but it must not pretend that the full pipeline is complete if it is not.

## Component boundary

`carbonstack` owns docs, registry/reference classification, adversarial seed cases, validation profile, report schema, and claim/nonclaim report surfaces.

`carbonstack-comms` owns component-local state classification and any non-secret dry-run fixture for Comms-owned state.

`carbonstack-cypher` remains coordination/server inventory only. Cypher DB/schema/path facts may be inventoried, but Cypher must not become a trust, identity, plaintext, secret-backup, restore, repair, or migration authority in this Gate D pass.

`carbonstack-os` remains future constrained-appliance context only.

## Allowed bounded surfaces

Gate D may model or classify:

- state export inventory;
- restore classification dry-run;
- migration compatibility dry-run;
- backup manifest model;
- rollback metadata inspection.

These surfaces must classify or refuse only. They must not repair, migrate, restore secrets, import trust, or destructively clean live state.

## Forbidden behavior

Secret-bearing backup restore is forbidden.

Encrypted vault claim is forbidden.

Hardware-backed storage claim is forbidden.

Automatic migration is forbidden.

Silent repair is forbidden.

Silent signer/provider/group regeneration is forbidden.

Silent trust import is forbidden.

Destructive cleanup without explicit contract is forbidden.

Gate C trust-candidate state is referenced inventory only. It is not a backup target, restore authority, or silent trust-import surface in Gate D.

## Done means

Gate D closes only if current state/recovery/vault-backup lineage is reconciled with current code, bounded classification/dry-run surfaces exist where safe, safety-sensitive state continues to refuse ambiguity, and no one can reasonably mistake the layer for production secure storage.
