# Gate F F7 Manual Release Handoff

Status: accepted implementation document
Scope: v0.7.x Gate F F7

## Manual release posture

The v0.8.0 public release remains operator-controlled.

The operator will provide:

- previous release markdown scaffold;
- previous release visual assets;
- previous attached-file component list;
- target release link or Gitea release creation surface;
- explicit confirmation to create and upload public release assets.

F7 may generate a release notes scaffold, checklist, and handoff report under temporary validation output.

F7 must not publish, upload, tag, create, or otherwise perform the public release.

## Manual checklist

1. Review final F7 log.
2. Generate and accept the post-F7 private LogDoc and Breakpoint.
3. Prepare release notes from the scaffold.
4. Verify source heads.
5. Verify command reference entries.
6. Run final validation commands.
7. Confirm nonclaims.
8. Manually create the v0.8.0 pre-release on Gitea.
9. Manually attach expected artifacts and visuals.
10. Capture public release URL.
11. Generate post-release PRIME continuity artifact.
12. Deprecate the v0.8.0 EVERGREEN roadmap.
13. Start v0.9.x adversarial roadmap Q/A.

## Nonclaims

This handoff does not create release artifacts and does not upload or publish anything.
