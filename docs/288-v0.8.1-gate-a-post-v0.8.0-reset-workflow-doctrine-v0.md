## Purpose

This document closes the post-v0.8.0 reset contract for the active v0.8.x epoch. It accepts the operator-provided v0.9.0 EVERGREEN roadmap as the active planning authority after the public v0.8.0 release and preserves CarbonStackLogDocV0.8.0PRIME as the archived v0.7.x continuity source.

The roadmap document is an external accepted planning artifact for this gate. It is not required to exist inside the WSL workspace or inside the carbonstack repository. This is deliberate: Gate A records the accepted authority boundary without pretending that the roadmap PDF is a tracked runtime, registry, or release asset.

Gate A is not an implementation feature gate. It exists so future work does not start from memory, from v0.7.x momentum, or from a stale interpretation of the public v0.8.0 release.

## LogDocV2 workflow doctrine

The v0.8.x workflow remains evidence-first and context-decay resistant:

- no implementation from memory;
- no-mutation preflight before high-surface work;
- contract freeze before tracked mutation;
- shadow-first implementation;
- proportionate validation rather than broad closure ladders for narrow changes;
- evidence-root logs with machine-readable status;
- No WSL LogDoc/Breakpoint generation;
- Markdown LogDocs carry the working ledger;
- JSON Breakpoints remain lean and current-state oriented;
- public release text remains concise and nonclaim-safe.
