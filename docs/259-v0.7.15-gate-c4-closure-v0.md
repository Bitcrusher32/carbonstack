# Gate C4 Closure

Status: accepted closure document  
Scope: v0.7.x Gate C4

## Closed behavior

Gate C4 is closed when:

- `state-write-policy-dev` exists;
- `state-write-policy-dev` profile passes;
- the report schema `carbonstack-state-write-policy-report/v0` is emitted;
- C1/C2/C3 report writers are classified as atomic generated evidence writers;
- B5d/B6 receipt writers are classified as atomic lock-guarded receipt writers;
- B8 workflow report writer is classified as an atomic report writer;
- replay/partial-state behavior for B5d/B6/B8 is represented;
- direct local state/trust/candidate writes are classified as future-hardening warnings;
- sidecar/Cypher/evidence roots are classified only;
- command reference and registry metadata remain current;
- missing nonclaims remain zero.

## What C4 prepares

C4 prepares C5 by giving Gate C a machine-readable write-policy and partial-state map without forcing risky broad runtime writer rewiring.

C5 should close Gate C by proving C1-C4 surfaces together and preserving no-silent repair/migration semantics.

## What C4 does not do

C4 does not migrate, repair, relocate, delete, clean, or silently normalize state. It does not claim runtime production safety.
