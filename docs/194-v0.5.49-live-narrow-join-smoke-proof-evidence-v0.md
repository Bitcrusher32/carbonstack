## 1. Purpose

This document records the first successful live no-ack narrow join smoke proof after the v0.5.48 runbook and v0.5.49 evidence checklist.

This is evidence for one dev/pre-alpha command sequence.

It is not a validation profile.

It is not a local-backbone claim.

        carbonstack-v0549-conversation;
    ACK_AFTER_JOIN unset.

## 3. Setup lesson

The first no-ack smoke attempt against older sidecar labels failed before KeyPackage submission because the Bob sidecar device already had provider storage:

    device provider storage already exists

This was not a Relay Space failure.

The successful run required fresh sidecar labels and a fresh conversation label.

Future smoke/validation work must either:

    create isolated sidecar labels per run;
    use isolated sidecar state roots;
    or define explicit safe cleanup behavior.
