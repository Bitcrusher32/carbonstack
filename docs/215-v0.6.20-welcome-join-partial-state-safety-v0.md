# CarbonStack v0.6.20 Welcome Join Partial-State Safety v0

Status: implementation checkpoint for failed Welcome join sidecar-state safety.

## Problem

v0.6.20A/v0.6.20B recon showed that a corrupt Relay Welcome did not ack and did not drain Bob's Relay inbox, but the failed sidecar `conversation-join` left final-path Bob conversation state behind.

Observed failure shape:

    corrupt Welcome join:
        no ack
        no Relay inbox drain

    restored valid Welcome join:
        conversation_already_exists

Manual quarantine of the failed Bob conversation directory allowed restored valid Welcome join to succeed.

## Fix target

The fix belongs in the OpenMLS sidecar state boundary, not in Cypher ack ordering and not in OpenMLS dependency/version selection.

The sidecar must not create/promote durable final conversation state until join state is complete enough to be persisted and reload-checked.

## Patch behavior

`join_dev_conversation` now uses staging/promotion behavior:

1. Validate existing final conversation state is absent.
2. Use a staging conversation directory during join materialization.
3. Persist provider storage and summaries under the staging directory.
4. Reload-check the staged provider storage.
5. Promote the staging directory to the final conversation directory only after successful materialization.
6. Remove failed staging state on materialization errors.

Invalid/corrupt Welcome artifacts should fail with `welcome_invalid` and leave no final Bob conversation directory.

## Validation meaning

The regression test proves:

    corrupt Welcome -> conversation-join fails
    corrupt Welcome -> no final Bob conversation directory remains
    restored valid Welcome -> conversation-join succeeds with the same conversation label
    valid join -> final conversation summary/provider storage/join summary exist

This does not create a runner profile yet.

A later `same-state-welcome-join-failure-dev` profile should only be added after this patch is validated in the live same-state runner context.
