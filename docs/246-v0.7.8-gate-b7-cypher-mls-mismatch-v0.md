# Gate B7 Cypher/MLS Mismatch Inspection and Refusal

Status: accepted implementation document  
Scope: v0.7.x Gate B7  
Command: `openmls-cypher-mls-mismatch-inspect-dev`  
Profile: `cypher-mls-mismatch-dev`

## Summary

B7 introduces an explicit dev/pre-alpha mismatch inspection and refusal surface between Cypher Relay Space routing membership and local OpenMLS group/conversation state.

This is not a workflow engine. It is the bounded refusal leaf that future workflow orchestration must call before unsafe send, join, ACK, or lifecycle progression.

## Command

`openmls-cypher-mls-mismatch-inspect-dev` accepts an explicit Cypher member-state snapshot and local MLS/receipt evidence, then emits a deterministic classification.

Required flags:

- `--relay-space`
- `--cypher-member-state`

Important optional flags:

- `--state`
- `--mls-group-state`
- `--sidecar-dir`
- `--sidecar-device-label`
- `--conversation`
- `--conversation-state`
- `--keypackage-receipt`
- `--welcome-receipt`
- `--allow-refusal-exit-zero`

## Classifications

The B7 leaf recognizes:

- `aligned`
- `relay_member_active_but_mls_group_absent`
- `relay_member_inactive_but_mls_group_present`
- `welcome_receipt_joined_but_cypher_member_inactive`
- `keypackage_receipt_exists_but_cypher_member_inactive`
- `mls_conversation_present_wrong_relay_space`
- `local_device_id_mismatch`
- `sidecar_device_label_mismatch`
- `conversation_label_mismatch`
- `unsupported_or_unknown_state_version`
- `stale_or_ambiguous`
- `incomplete_local_consume_or_join`

Unsafe states return `action: refuse`.

## Authority split

B7 preserves the authority split:

- Cypher remains routing, delivery, and ACK authority.
- The OpenMLS sidecar remains cryptographic group authority.
- Comms owns local coordination and mismatch reporting.
- Relay Space membership is not MLS group membership.
- MLS group presence is not trust or verified identity.

## Nonclaims

B7 does not:

- repair state;
- rejoin automatically;
- mutate Cypher state;
- mutate MLS state;
- promote trust;
- verify identity;
- create a workflow engine;
- close Gate B.
