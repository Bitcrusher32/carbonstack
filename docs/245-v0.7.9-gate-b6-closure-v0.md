# Gate B6 Closure

Status: accepted closure document  
Scope: v0.7.x Gate B6

## Closed behavior

Gate B6 is closed as a dev/pre-alpha Welcome lifecycle slice.

Closed surfaces:

- `openmls-relay-add-member-dev` for dev add-member and Welcome production/submission;
- `openmls-relay-welcome-submit-dev` for explicit Welcome transport;
- `openmls-relay-welcome-inbox-dev` for explicit Welcome fetch/write inspection;
- `openmls-relay-join-dev` for legacy/manual join scaffold with optional ACK-after-join;
- `openmls-relay-welcome-consume-dev` for bounded B6 consume/join/ACK-after-join;
- `welcome-lifecycle-dev` for validation.

## Boundary

B6 closes Welcome lifecycle mechanics only.

It does not close:

- B7 Cypher/MLS mismatch inspection and refusal;
- trust promotion;
- verified identity;
- secure enrollment;
- production E2EE;
- public directory behavior;
- complete operational aggregate;
- hostile-server safety.

## Next gate

B7 is next and must start with a separate deep recon before mutation.
