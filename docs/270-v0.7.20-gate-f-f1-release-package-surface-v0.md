# Gate F F1 Release Package Runtime Surface

Status: accepted implementation document
Scope: v0.7.x Gate F F1
Profile: gate-f-release-package-surface-dev

## Summary

Gate F F1 classifies the current release, package, runtime, helper, and hygiene surfaces before any v0.8.0 release-candidate work.

F1 is not a release rehearsal. It does not create a release, upload assets, stage a package, publish a package, promote full-runtime-dev, or implement migration.

## Why F1 exists

Gate F0 found a dense historical release and package surface:

- stage-v0.5.0-package.sh
- stage-v0.6.0-package.sh
- stage-v0.7.0-package.sh
- rehearse package scripts
- release-snapshot
- full-validate-release
- local-cypher
- integrated-runtime-dev
- current Gate D and Gate E profiles
- old release docs and package-root rehearsal docs

F1 freezes the authority map so later Gate F work does not accidentally treat older package scaffolds as current v0.8.0 release authority.

## Accepted classification

F1 classifies:

- full-validate-release as release-package validation, not release creation.
- release-snapshot as package-root layout, checksum, and core validation, not packaging or upload.
- local-cypher as a release validation component, not deployment.
- integrated-runtime-dev as an older runtime validation profile, not full-runtime-dev.
- stage-v0.7.0-package.sh as the strongest historical package staging scaffold, not current v0.8.0 staging.
- stage-v0.5.0 and stage-v0.6.0 scripts as historical scaffolds.
- rehearse scripts as historical rehearsal scaffolds.
- repo-root cypher.db as a non-destructive hygiene classification target.

## F1 nonclaims

F1 does not claim:

- v0.8.0 release readiness
- package/runtime candidate readiness
- release creation
- release upload
- package publication
- package staging execution
- full-runtime-dev
- migration implementation
- service/systemd/helper install
- public ingress
- containers
- TUI
- verified identity
- trust promotion
- vault security
- backup/restore
- PQ/hybrid support
- Android
- CarbonStackOS
