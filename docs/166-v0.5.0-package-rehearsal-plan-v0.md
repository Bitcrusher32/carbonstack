## 4. New staging helper

New script:

    scripts/stage-v0.5.0-package.sh

Default staging target:

    /tmp/carbonstack-v0.5.0-rehearsal/stage/package

Behavior:

    requires git, tar, and python3
    requires clean live git checkouts for carbonstack, carbonstack-comms, and carbonstack-cypher
    copies tracked repository contents using git archive
    excludes .git automatically
    excludes untracked generated/private/build artifacts
    writes release metadata skeleton files
    checks the staged package for forbidden generated/private/build artifacts
    prints the staged package path
