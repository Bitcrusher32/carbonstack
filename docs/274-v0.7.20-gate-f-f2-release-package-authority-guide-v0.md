# Gate F F2 Release Package Authority Guide

Status: accepted operator guide
Scope: v0.7.x Gate F F2

## Purpose

This document prevents historical release and package helpers from being mistaken for current v0.8.0 release authority.

## Current classifications

full-validate-release is release-package validation, not release creation.

release-snapshot is package-root layout, checksum, and core validation, not packaging or upload.

local-cypher is a useful release validation component, not deployment.

integrated-runtime-dev is an older integrated runtime validation surface, not full-runtime-dev.

stage-v0.7.0-package.sh is the strongest historical package staging scaffold, not current v0.8.0 staging.

stage-v0.5.0-package.sh and stage-v0.6.0-package.sh are historical scaffolds.

rehearse package scripts are historical rehearsal scaffolds.

## manual release creation

manual release creation remains the operator-controlled process.

When v0.8.0 release time arrives, the operator will provide previous release markdown, visual, attached file components, and release link as a template scaffold.

F2 does not automate that release flow.

## not package publication

F2 is not package publication.

F2 does not upload release assets.

F2 does not tag a release.

F2 does not create a public release.

F2 does not run package staging.

F2 does not claim v0.8.0 release readiness.

## Later Gate F work

A later Gate F package/runtime candidate should decide whether to adapt stage-v0.7.0-package.sh or write a new v0.8.0 staging path.

A later Gate F release-candidate closure should produce evidence for the manual release flow.

The final v0.8.0 release itself remains operator-driven.
