# Gate B v0.8.x Adversarial Harness Contract

Status: dev/pre-alpha Gate B contract artifact  
Checkpoint: v0.8.2 Gate B adversarial harness seed  
Scope: adversarial case registry, report schema, severity/disposition model, and one low-risk seed case  

## Purpose

Gate B creates the minimum durable adversarial harness infrastructure required before broad attack passes begin.

Gate B is not comprehensive adversarial coverage. It is the framework that future v0.8.x Gates C-H can use to record case IDs, surfaces, expected warnings/refusals, severities, evidence, findings, regressions, and nonclaim preservation.

## Mutation boundary

Initial Gate B implementation is carbonstack-only.

Allowed:

- `carbonstack/registry/adversarial_cases.v0.yaml`;
- Gate B Markdown docs;
- `carbonstack/tools/carbonstack-validate` profile and tests;
- command registry/reference updates;
- docs index update.

Forbidden for this seed:

- `carbonstack-comms` mutation;
- `carbonstack-cypher` mutation;
- `carbonstack-os` mutation;
- runtime state mutation;
- `cypher.db` deletion;
- release/package creation;
- LogDoc/Breakpoint generation inside WSL;
- broad Relay/native/trust attack implementation before the harness contract exists.

## Case registry contract

Case registry path:

```text
carbonstack/registry/adversarial_cases.v0.yaml
```

Registry schema marker:

```text
carbonstack-adversarial-case-registry/v0
```

Case IDs use stable semantic IDs, not patch-version IDs:

```text
ADV-<SURFACE>-<SEMANTIC-NAME>-<NNN>
```

The first seed case is:

```text
ADV-TRUST-RELAY-MEMBERSHIP-NOT-TRUST-001
```

## Case object fields

Required case object fields:

- `case_id`;
- `title`;
- `status`;
- `surface`;
- `case_family`;
- `severity`;
- `finding_disposition`;
- `preconditions`;
- `attack_or_fault`;
- `expected_refusal_or_warning`;
- `expected_nonclaim_preservation`;
- `evidence_paths`;
- `fix_required`;
- `regression_profile`;
- `future_gate_links`.

## Severity model

Canonical severity labels:

- `release-blocker`;
- `high`;
- `medium`;
- `informational`;
- `accepted-risk`.

Severity must not absorb finding disposition. `accepted-risk` remains a severity label for cases or findings whose risk is intentionally accepted; it must not be emitted merely because the schema supports it.

## Finding disposition model

Finding disposition is separate from severity.

Initial dispositions:

- `passed`;
- `failed`;
- `not_executed`;
- `seed_contract_only_not_executed`;
- `fixed`;
- `deferred`;
- `nonclaim_preserved`;
- `accepted_risk`;
- `not_applicable`.

## Report schema contract

Gate B report schema marker:

```text
carbonstack-adversarial-harness-report/v0
```

The first Gate B report is allowed to be a seed-contract report where no adversarial case is executed yet. This is intentional: the purpose is to prove the registry/report/profile flow before broad attack surfaces exist.

Required summary counters:

- cases total;
- cases executed;
- cases passed;
- cases failed;
- release blockers;
- high findings;
- medium findings;
- informational findings;
- accepted risks;
- nonclaims preserved.

## Validation posture

For this narrow framework seed, use focused validation:

- initial clean guards across all repos;
- shadow mutate `carbonstack` only;
- parse/check adversarial case registry YAML;
- render generated command reference and check freshness;
- gofmt validator sources;
- `go test ./...` in `carbonstack/tools/carbonstack-validate`;
- `gate-b-adversarial-harness-dev` profile;
- `registry-lookup` for `runner.gate-b-adversarial-harness-dev`;
- live copy and repeat focused checks;
- commit/push with one retry;
- final clean-state across all repos.

Do not run broad integration ladders for the narrow Gate B framework seed unless the seed exposes an actual integration dependency. However, use broad ladders when testing full CarbonStack integration or closure, because some defects only appear under broad verification.

- malicious-relay safety;
- verified identity;
- full trust promotion;
- secure enrollment;
- cryptographic identity binding;

- TUI readiness;
