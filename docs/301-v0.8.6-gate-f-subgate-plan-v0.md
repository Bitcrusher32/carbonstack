# Gate F v0.8.x Subgate Plan

Status: accepted subgate split for Gate F  

## F1 — Contract / model / case matrix

Mutation scope: `carbonstack` only.

Reason: `carbonstack` owns docs, registry, command reference, validation profiles, report schemas, and claim/nonclaim classification. F1 freezes the shape before material Comms/Cypher probes are built.

## F2 — Component runtime/process probes

Mutation scope: `carbonstack`, `carbonstack-comms`, and `carbonstack-cypher` as justified by evidence.

Expected work:
- disposable run-root process probes;
- DB/config/log/state-root path tests;
- Comms CLI terminating inspection and runtime-root probes where component-owned;
- Cypher config/env/DB/process tests where server-local;
- no OS mutation.

## F3/F4 — Full validation and real Debian host validation

Order:
1. full WSL/local validation;
2. clean pushed repos;
3. cache-free export or bounded git pull plan;
4. Debian host snapshot;
5. slow laptop execution only with bounded commands and disposable roots.

No major surprise bug should be discovered first on the old slow Debian laptop.
