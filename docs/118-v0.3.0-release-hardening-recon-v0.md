## 10. Cypher status

`carbonstack-cypher` appears mostly aligned for the release-hardening pass.

Current Cypher public docs already say:

- stores opaque envelopes;
- does not handle plaintext;
- does not decide trust;
- not production-certified;
- not externally audited;
- supports OpenMLS artifact envelope content types;
- supports payload metadata;
- supports queued-only inbox and ack behavior.

No Cypher code change is expected for the next release-surface implementation rung.
