# v0.8.10 Gate G4 Service/Systemd/Helper Contract v0

## Status

Gate G4a implementation contract.

Schema marker: `carbonstack-gate-g4-service-systemd-helper-contract/v0`

## Purpose

Gate G4a freezes the local/private service, systemd, and helper substrate contract before any install-capable or host-lifecycle implementation exists.

It extends the Gate G3 `operator-lifecycle-dev` decision by making the next lifecycle lane explicit: local/private service-management semantics may be modeled, checked, and reported, but not installed, daemonized, public-bound, containerized, released, or promoted into `full-runtime-dev`.

## Allowed G4a mutation

G4a may add CarbonStack docs, a CarbonStack registry entry, command reference regeneration, a CarbonStack validator profile, CarbonStack validator tests, a G4a safe-summary/report schema, a service/systemd/helper contract matrix, and explicit nonclaims/refusal posture.

G4a must not add actual service installation, system-level systemd units, user-level systemd units intended to be installed, `sudo` or `systemctl` execution, public bind implementation, public ingress implementation, container files, Dockerfile or compose files, release/package mutation, `full-runtime-dev` promotion, or mutation of `carbonstack-comms`, `carbonstack-cypher`, or `carbonstack-os` unless a later contract explicitly authorizes it.

## Root policy

G4a requires explicit classification of `CONFIG_ROOT`, `STATE_ROOT`, `RUNTIME_ROOT`, `EVIDENCE_ROOT`, `LOG_ROOT`, `DB_PATH`, `MIGRATIONS_PATH`, and `GENERATED_ARTIFACT_ROOT`.

```text
unknown_root=refuse
ambiguous_root=refuse
conflicting_config=refuse
implicit_default_public_bind=refuse
evidence_root=never_formal_git_repo
generated_artifact_cleanup=only_profile_owned_artifacts_from_same_run
destructive_cleanup=blocked
```

## Lifecycle verbs

G4a may model `check-config`, `dry-run`, `status`, `start`, `stop`, and `restart` as semantic/report states. G4a must not perform host lifecycle actions. `remove` remains blocked except for future explicitly contracted cleanup of profile-owned generated artifacts.

## Public bind and public ingress

Public ingress remains blocked until G5 is explicitly reconfirmed.

```text
PUBLIC_BIND_DEFAULT=refuse
PUBLIC_BIND_IF_DETECTED=loud_report
PUBLIC_INGRESS_IMPLEMENTED=false
G5_REQUIRED_FOR_PUBLIC_INGRESS=true
GATE_H_REQUIRED_IF_G5_EXISTS=true
```

Ambient host listeners are host context evidence, not automatically CarbonStack exposure. G4 profiles must classify them without claiming public-ingress safety.

## Logging and redaction

G4a carries `ADV-NATIVE-LOG-LEAKAGE-001`.

Default profile output must be safe-summary only. Detailed reports belong under the evidence root. Sensitive markers such as account identifiers, device identifiers, invite codes, KeyPackage details, Relay Space identifiers, local DB paths, state roots, runtime roots, secrets, private keys, passwords, and tokens must not be promoted into public-style output.

## Nonclaims

G4a is not service readiness, systemd readiness, helper install readiness, public-ingress safety, public deployment readiness, container readiness, deployment hardening certification, production security, production E2EE, verified identity, trust promotion, secure enrollment, malicious-relay safety, metadata privacy, external audit, external pen-test completion, PQ/hybrid security, Android readiness, CarbonStackOS implementation, TUI/public UX, `full-runtime-dev` promotion, or zero-leakage public logging posture.
