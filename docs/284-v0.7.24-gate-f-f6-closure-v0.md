# Gate F F6 Closure

Status: accepted closure document
Scope: v0.7.x Gate F F6

## Closure meaning

Gate F F6 is closed when gate-f-package-runtime-candidate-dev passes and the registry contains runner.gate-f-package-runtime-candidate-dev.

Closure means a disposable package/runtime candidate root shape is validated for release-candidate closure work.

Closure does not mean a public release was created.

Closure does not mean a package was published.

Closure does not mean legacy package staging scripts were executed.

Closure does not mean full-runtime-dev is promoted.
