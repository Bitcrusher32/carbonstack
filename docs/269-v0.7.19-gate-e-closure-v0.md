# Gate E Closure

Status: accepted closure document
Scope: v0.7.x Gate E manual-private native deployment

## Closure meaning

Gate E is closed when gate-e-native-deployment-closure-dev passes.

Closure means CarbonStack has a dev/pre-alpha, manual-private, single-host native deployment proof model with:

- explicit deployment-root fixture;
- explicit env;
- explicit loopback Cypher;
- explicit Cypher DB root;
- explicit migrations root;
- explicit Comms state root;
- explicit evidence/log/temp roots;
- Cypher start/stop/restart proof;
- terminating Cypher config inspection;
- Gate C state-policy inspection over deployment roots;
- registry/reference/nonclaim validation.

Gate F must begin with fresh preflight/contract freeze. It must not assume release readiness merely because Gate E is closed.

- production readiness;
- production E2EE;
- verified identity;
- trust promotion;
- hostile-server safety proof;
- public ingress;
- semi-persistent service install;
- systemd readiness;
- container readiness;
- TUI readiness;
- vault security;
- backup/restore safety;
- PQ/hybrid support;
- Android;
- CarbonStackOS implementation;
- v0.8.0 release readiness by itself.
