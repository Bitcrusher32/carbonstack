## Safe-summary stdout

The profile must print only contract posture: G4 mode, service model, install status, privilege boundary, public-bind default, public-ingress status, container deferment, `full-runtime-dev` reservation, root/refusal posture, carried findings, and nonclaims.

It must not print local secrets, tokens, invite codes, account IDs, device IDs, Relay Space IDs, KeyPackage payloads, private keys, passwords, DB paths, state roots, runtime roots, or detailed local listener state.

## Detailed evidence

Detailed evidence belongs in timestamped evidence-root logs produced by outer scripts. The profile is allowed to validate contract files and report shape but is not a host service-management tool.

## Nonclaims

The report is not service readiness, systemd readiness, helper install readiness, public-ingress safety, public deployment readiness, container readiness, deployment hardening certification, production security, production E2EE, verified identity, trust promotion, secure enrollment, malicious-relay safety, metadata privacy, external audit, external pen-test completion, PQ/hybrid security, Android readiness, CarbonStackOS implementation, TUI/public UX, full-runtime-dev promotion, or zero-leakage public logging posture.
