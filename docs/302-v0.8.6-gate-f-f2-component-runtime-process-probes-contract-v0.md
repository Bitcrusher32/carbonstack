## Purpose

F2 turns the F1 carbonstack-only contract/model into component-owned probe substrates in `carbonstack-comms` and `carbonstack-cypher`.

F2 is deliberately before deep WSL process testing and before real Debian laptop testing. It creates and validates the component classifications needed to make deep process execution less surprising.

## Mutation scope

F2 mutates:

- `carbonstack` for docs, registry, command reference, validation profile, and claim/nonclaim classification;
- `carbonstack-comms` for Comms-owned native process probe model and tests;
- `carbonstack-cypher` for Cypher-owned native process probe model and tests.

F2 does not mutate `carbonstack-os`.

## Component responsibilities

Comms F2 owns:

- runtime/state-root path classification;
- generated artifact location classification;
- sensitive output marker classification;
- CLI terminating-inspection classification;
- partial-state/run-root foot-gun classification substrate.

Cypher F2 owns:

- config/env redaction model;
- DB path classification;
- port collision classification;
- sensitive output marker classification;
- terminating inspection support boundary;
- process/DB/log disposable-root classification substrate.

## Nonclaims

F2 is not deep WSL process testing. F2 is not real Debian laptop validation. F2 is not service readiness, systemd readiness, helper install readiness, public ingress, container readiness, production security, external audit, or external pen-test completion.
