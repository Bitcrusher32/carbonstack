# Gate E E3 Native Deployment Closure

Status: accepted implementation document
Scope: v0.7.x Gate E E3
Profile: gate-e-native-deployment-closure-dev

## Summary

Gate E E3 closes the manual-private native deployment line by adding a closure profile over:

- Gate E E1 manual-private native deployment proof;
- Gate E E2 Cypher terminating config inspection;
- registry/reference/nonclaim validation.

## Closure model

Gate E is closed only for the explicit manual-private native deployment model.

This means:

- one explicit deployment-root fixture exists and is mechanically validated;
- Cypher can be started/stopped/restarted with explicit env and deployment-owned DB;
- Cypher can now be inspected with terminating --help, --print-config, and --check-config;
- deployment roots are inspected by Gate C state-policy surfaces;
- nonclaims remain visible.

## Still not included

Gate E closure does not implement:

- semi-persistent service deployment;
- systemd units;
- helper installation;
- public ingress;
- containers;
- TUI;
- full-runtime-dev;
- verified identity;
- trust promotion;
- vault/backup/restore;
- production E2EE;
- PQ/hybrid support;
- Android;
- CarbonStackOS.

After E3, the next safe action is a private LogDoc plus Breakpoint update before Gate F preflight or any additional native-deployment expansion.
