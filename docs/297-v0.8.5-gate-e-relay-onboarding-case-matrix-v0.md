## Carry-forward boundaries

Gate C trust-candidate state must not auto-promote through Relay/onboarding.

Gate D state/recovery dry-run classification must not silently repair rollback/replay.

Cypher remains narrow relay/storage/coordination and server-side membership/routing authority only. It is not plaintext authority, MLS parser, trust authority, identity authority, backup/restore authority, or group authority.
