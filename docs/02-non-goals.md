# Non-Goals

CarbonStack is intentionally limited.

## CarbonStack Is Not

- a general smartphone OS
- a browser platform
- an app ecosystem
- a cloud sync platform
- a Signal clone
- a media consumption platform
- a universal Android compatibility layer
- a convenience-first communications app

## Explicit Non-Goals

CarbonStack does not aim to support:

- browser engines
- WebView-dependent apps
- Google Play Services dependency
- arbitrary APK installation
- general file managers
- rich notifications
- link previews
- assistant features
- third-party keyboards
- third-party accessibility services
- general URI handling
- automatic cloud backup
- general media ecosystems

## Security Honesty

CarbonStack may reduce attack surface.

CarbonStack does not make compromised endpoints safe.
