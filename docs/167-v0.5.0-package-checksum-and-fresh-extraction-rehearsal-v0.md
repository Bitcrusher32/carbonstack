# CarbonStack v0.4.22 v0.5.0 Package Checksum and Fresh Extraction Rehearsal

Status: package checksum / archive / fresh extraction rehearsal checkpoint
Scope: late v0.4.x to v0.5.0 minor epoch release runway
Primary environment: WSL Debian

## 1. Purpose

v0.4.22 builds on v0.4.21 package staging.

v0.4.21 added:

    scripts/stage-v0.5.0-package.sh
    docs/166-v0.5.0-package-rehearsal-plan-v0.md

v0.4.22 adds a repeatable rehearsal helper:

    scripts/rehearse-v0.5.0-package.sh

The helper stages the package, writes checksums, verifies checksums, archives the package, extracts it fresh, verifies checksums again, and runs `full --clean-generated` from the fresh extraction.

## 2. Rehearsal flow

    stage v0.5.0 package skeleton
    write release/checksums.txt in staged package
    verify checksums in staged package
    archive staged package
    fresh extract archive into a throwaway root
    verify checksums from fresh extraction
    run full from fresh extraction with --clean-generated
    confirm release metadata files exist
    confirm carbonstack-os is excluded
    confirm known generated/private/build roots are absent after cleanup

## 3. Important v0.4.0 continuity rule

This follows the v0.4.0/v0.3.36 package rehearsal pattern:

    do not treat the live umbrella as the release package root
    use a throwaway staged package root
    write checksums only in the package root
    archive the package
    validate from a fresh extraction

During `full`, `release-snapshot` runs `core` before `local-cypher`.

Because `core` can generate OpenMLS sidecar state and Rust build artifacts, `local-cypher` may observe known generated roots during its artifact scan. This is not automatically a failure. The release-relevant final condition is that `--clean-generated` removes the known roots by the end.

## 5. Release-helper command surface

The v0.5.0 release-helper system now has two helpers:

    scripts/stage-v0.5.0-package.sh
    scripts/rehearse-v0.5.0-package.sh

`stage-v0.5.0-package.sh` stages a clean package skeleton and metadata.

`rehearse-v0.5.0-package.sh` performs the checksum/archive/fresh-extraction/full validation rehearsal.

These helpers should be represented in the known-good command registry and current release-helper docs before the v0.4.22 rung is closed.
