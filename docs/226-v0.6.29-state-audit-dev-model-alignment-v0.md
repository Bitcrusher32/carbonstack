# CarbonStack v0.6.29 state-audit-dev model alignment v0

Status: implementation/result note for the v0.6.29C state-audit-dev model-alignment patch.

Scope: records a narrow output/model alignment patch for the existing `state-audit-dev` proto-substrate inventory surface.

This note does not describe a vault implementation.

This note does not claim secure storage.

This note does not claim backup/restore.

This note does not claim PQ/hybrid security.

## 1. Purpose

v0.6.29A identified the bounded state substrate direction.

v0.6.29B documented the bounded state substrate mechanics and selected `state-audit-dev` as the current proto-substrate / non-mutating inventory precursor.

v0.6.29C inspected the existing implementation and kept the existing command rather than creating a new command or wrapper.

The patch aligns `state-audit-dev` output with the v0.6.29 model by adding explicit state-boundary fields.

## 2. Changed behavior

`state-audit-dev` remains:

- dev-only;
- inventory/check oriented;
- non-mutating;
- not secure storage;
- not backup/restore;
- not trust verification;
- not PQ.

The command output now includes report-level state-boundary markers:

- `state_boundary_model_version`;
- `state_boundary_role`;
- `proto_substrate`;
- `pq_tags_reserved_not_implemented`.

Domain output now includes:

- `authority_class`;
- `sensitivity_class`;
- `no_silent_rule`;
- `boundary_warning`;
- `cypher_inventory_only`.

## 3. JSON behavior

Existing JSON behavior remains through:

    --format json

This patch does not add `--json`.

Reason:

- `--format json` already exists;
- adding `--json` would expand the flag surface;
- the current rung is output/model alignment, not CLI alias expansion.

## 4. Nonclaims

This patch does not add:

- encryption;
- secure vault;
- production key storage;
- backup;
- restore;
- migration;
- PQ;
- trust mutation;
- identity verification;
- Cypher mutation;
- full/release-snapshot inclusion.

## 5. Validation expectation

Validation should prove:

- text output includes state-boundary fields;
- JSON output includes state-boundary fields;
- raw state contents are not printed;
- mutation remains disallowed;
- existing registry/generated reference remains deterministic unless registry metadata is deliberately changed.
