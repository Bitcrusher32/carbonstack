## 6. Primary finding

The v0.3.0 release snapshots are runnable enough to execute the core local validation and the underlying OpenMLS real-Cypher backbone proof.

The public Comms self-test wrapper is not release-snapshot-safe yet because it depends on `check-no-rust-artifacts.ps1`, and that script assumes a Git working tree.

v0.3.4 should make the artifact guard work without `.git/`.

## 7. Required v0.3.4 fix

`carbonstack-comms/scripts/check-no-rust-artifacts.ps1` should support two modes:

    Git working tree mode:
        use git-tracked file checks.

    Source snapshot mode:
        detect that .git is unavailable;
        print a clear degraded-mode message;
        run a filesystem scan for forbidden generated/private/build artifacts;
        exit 0 if no forbidden artifacts are found.

The public self-test wrapper should pass from a clean release source snapshot after this fix.

## 8. Post-test generated artifact scan

The post-test scan found generated artifacts after validation.

This is expected after running tests, but those artifacts must remain excluded from release source snapshots.

Generated categories to track include:

    OpenMLS sidecar generated state;
    Rust target/build output;
    temporary SQLite databases;
    temporary Cypher validation files;
    Go/Rust test output.

These are post-validation outputs, not shipped release contents.
