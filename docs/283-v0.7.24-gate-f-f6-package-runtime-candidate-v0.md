# Gate F F6 Package Runtime Candidate Validation

Status: accepted implementation document
Scope: v0.7.x Gate F F6
Profile: gate-f-package-runtime-candidate-dev

## Summary

Gate F F6 validates a disposable package/runtime candidate root shape for the v0.8.0 manual-private release runway.

F6 validates candidate layout and boundaries.

F6 does not create a release.

F6 does not upload a release.

F6 does not publish a package.

F6 does not execute legacy package staging scripts.

F6 does not promote full-runtime-dev.

## Root model

F6 separates:

- candidate root;
- package root;
- release artifact root;
- runtime deployment root;
- evidence root;
- report root;
- local state root.

The package root is for candidate metadata and layout validation.

The release artifact root is intentionally not populated with public release archives by F6.

The runtime deployment root models manual-private runtime placement, including config, logs, trust evidence, and state/cypher.

The evidence root and report root keep generated validation reports separate from source and runtime state.

## Prior art posture

Existing stage and rehearse scripts are classified as prior art.

F6 does not execute them.

Future execution requires a fresh explicit contract.

## F5 trust posture dependency

F6 includes the F5 basic local trust posture as a nonclaim-aware dependency.

That dependency does not become verified identity.

It does not become full trust promotion.

It does not become cryptographic identity binding.

## Nonclaims

F6 is not v0.8.0 release readiness by itself, not release creation, not release upload, not package publication, not package staging execution, not full-runtime-dev, not service/systemd/helper install, not public ingress, not container readiness, not TUI, not migration, not repair, not destructive cleanup, not verified identity, not trust promotion, not secure enrollment, not vault, not backup/restore, not PQ, not Android, and not CarbonStackOS.
