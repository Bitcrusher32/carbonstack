# Gate E v0.8.x Relay / Onboarding / MLS-Cypher Adversarial Contract

Status: dev/pre-alpha Gate E contract artifact

Report schema: `carbonstack-gate-e-relay-onboarding-adversarial-report/v0`  

## Purpose

Gate E attacks Relay/onboarding lifecycle work made real by v0.8.0 and sharpened by Gates B, C, and D.

Gate B provides the adversarial case registry/report/disposition substrate. Gate C provides local trust-candidate boundaries. Gate D provides state/recovery/no-silent boundaries. Gate E combines those into a Relay/onboarding adversarial classification pass.

## Required posture

KeyPackage and Welcome remain onboarding artifacts, not normal messages.

ACK happens only after successful state establishment where the contract requires it.

Cypher membership remains server-side coordination authority.

OpenMLS group state remains cryptographic group authority.

Mismatch refuses, warns, or enters recovery-required state; it does not silently self-heal.

Gate C trust-candidate state must not auto-promote through Relay/onboarding.

Gate D state/recovery dry-run classification must not silently repair rollback/replay.

## Mutation scope

Allowed in this Gate E pass:

- `carbonstack` docs, registry, generated reference, validation profile, and report schema.
- `carbonstack-comms` component-owned adversarial case classification model and tests.

Not mutated in this Gate E pass:

- `carbonstack-cypher`, because current server-side membership, routing, and KeyPackage surfaces were sufficient for classification from existing coverage.
- `carbonstack-os`.

## Abort conditions

Gate E must pause or fail if Cypher starts acting as plaintext, MLS parser, trust, identity, backup/restore, or group authority; if KeyPackage or Welcome starts being treated as normal message content; if ACK can happen after failed state establishment where the contract requires no ACK; if Relay/onboarding silently self-heals mismatched Cypher/MLS membership; if Gate C local trust candidate state silently promotes through Relay/onboarding; if Gate D state/recovery dry-run classification silently repairs state or imports trust; or if broad integration mutation becomes necessary without an explicit contract.

## Nonclaims

Gate E does not claim malicious-relay safety, metadata privacy, verified identity, hostile-server proof, production security, production E2EE, external pen-test completion, silent repair safety, silent trust promotion safety, public deployment readiness, external audit, certification, or general-public usability.
