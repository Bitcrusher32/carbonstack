## Initial severity posture

Release-blocker candidates:
- destructive cleanup outside disposable root;
- secret/private/token leakage in logs;
- state corruption or false success after foreground failure;
- service/public/container claim drift.

High candidates:
- DB path confusion;
- state root confusion;
- config/env misuse;
- migration path confusion;
- port collision;
- stale process confusion;
- restart/shutdown ambiguity;
- unsafe permissions.

Medium candidates:
- package-vs-runtime root confusion;
- generated artifact sprawl;
- CLI help/terminating-inspection inconsistency;
- slow Debian host/export feasibility hazard.

Informational:
- docs-only service/systemd/helper model notes.
