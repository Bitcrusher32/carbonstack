# CarbonStack v0.3.0 Minor Epoch Release

Status: experimental backbone release README
Release class: pre-alpha / experimental
Primary artifact: Cypher + Comms OpenMLS relay backbone

## 1. What am I looking at?

CarbonStack v0.3.0 is an experimental communications backbone release.

It is not a finished messenger.

It is not production-certified.

It is not externally audited.

It is not Android-ready.

It is not a complete secure communications product.

The current release exists to package a known-good local backbone proof:

    CarbonStackComms OpenMLS sidecar
    + CarbonStackCypher real local relay server
    + opaque OpenMLS artifact envelope relay
    + payload metadata validation
    + consume-then-ack semantics
    + OpenMLS backbone self-test harness

This release is for builders who want to inspect or build on the current relay backbone without reconstructing the OpenMLS/Cypher plumbing from scratch.

## 2. What is currently proven?

The current backbone proves a local OpenMLS relay lifecycle.

The known-good proof validates this path:

1. Bob exports an OpenMLS KeyPackage artifact.
2. CarbonStackCypher relays the KeyPackage as an opaque envelope.
3. Alice retrieves the envelope payload.
4. CarbonStackComms validates payload metadata before writing artifact bytes.
5. Alice consumes the KeyPackage through the OpenMLS sidecar.
6. Alice creates a Welcome artifact.
7. Cypher relays the Welcome as an opaque envelope.
8. Bob retrieves the envelope payload.
9. Comms validates payload metadata before writing artifact bytes.
10. Bob consumes the Welcome through the OpenMLS sidecar.
11. Alice protects an application-message artifact.
12. Cypher relays the application-message as an opaque envelope.
13. Bob retrieves the envelope payload.
14. Comms validates payload metadata before writing artifact bytes.
15. Bob consumes the application-message through the OpenMLS sidecar.
16. The plaintext matches.
17. Comms acknowledges envelopes only after the relevant sidecar consume command succeeds.

This proves a repeatable local experimental backbone lifecycle.

It does not prove production security.

## 7. Core terms

### Envelope

The server-visible relay unit stored by Cypher.

### Opaque payload

The base64-encoded payload carried in `ciphertext_b64`.

For OpenMLS artifacts, this is artifact data, not plaintext.

### Payload metadata

Cypher-computed metadata over decoded payload bytes:

    payload_sha256
    payload_size_bytes

Payload metadata is storage/transport sanity metadata.

It is not a trust root.

It does not prove OpenMLS authenticity.

### Sidecar consume

The OpenMLS sidecar successfully accepts and processes an artifact.

Current consume commands:

    conversation-add-member
    conversation-join
    message-open

### Ack

A recipient-device request marking an envelope handled in Cypher.

In the current Comms proof, ack is sent only after sidecar consume succeeds.

Cypher records ack.

Cypher does not know sidecar consume state.

## 9. Security status

This release is an experimental backbone proof.

The project uses OpenMLS through a dev-local sidecar.

The current sidecar state is development state.

The current local storage model is not a production secure vault.

The current relay server is not a complete hostile-server proof.

The current proof is useful because it validates a concrete relay lifecycle. It is not sufficient for production trust.
